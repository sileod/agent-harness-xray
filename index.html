Data Acquisition

A defensible comparison needs to label how each number was obtained. This project uses three evidence tiers:

  • Source-auditable: open-source agents where prompt templates, repo-map construction, and edit formats can be inspected directly.
  • Captured: request bodies observed from a controlled sandbox run, with credentials replaced by local dummy endpoints and real user config excluded.
  • Estimated: proprietary agents where only public docs, visible behavior, community reports, or package inspection are available. These values should be treated as directional.

Token Calculation

Prompt formats differ, so the useful baseline is not a single "the prompt" number. Separate at least these buckets:

  • Always-on baseline: identity, safety, response style, and built-in tool schemas that appear in a clean session.
  • Project dynamic: files such as CLAUDE.md, .cursor/rules/*.mdc, .windsurf/rules/*, and .github/copilot-instructions.md.
  • Session dynamic: cwd, OS, selected text, open tabs, diagnostics, git diff, MCP tool definitions, retrieved code chunks, and prior tool results.
  • Tokenizer: use the tokenizer matching the target model when possible. Otherwise mark counts as approximate and keep comparisons at the component level.

Sandboxed Extraction

The repository now includes tools/capture-agent.mjs plus scripts/xray-opencode.sh and scripts/xray-hermes.sh. They run an agent command with a temporary HOME, temporary XDG directories, dummy API keys, and local capture endpoints for OpenAI-, Anthropic-, and Google-style base URLs.

  • Use --fixture to point the agent at a synthetic project containing known rule files.
  • Use --allow-real-home only when you explicitly want the run to see your installed agent config.
  • Compare a blank fixture against a rule-heavy fixture to identify what is always present versus what is dynamically injected.
  • Captured request payloads are ground truth for what the agent attempted to send to the provider endpoint, not necessarily for provider-side tokenization.
